likelihood.model

An R package for specifying and working with likelihood models for statistical inference. The package provides a flexible, composable framework for building likelihood functions from independent contributions across different observation types.

Why likelihood.model?

Statistical inference often involves data with mixed observation types—some exact, some censored, some truncated. Traditional approaches require custom implementations for each scenario. likelihood.model provides a unified framework that:

  • Composes naturally: Build complex likelihoods from simple, independent contributions
  • Handles mixed data: Exact observations, right-censoring, left-censoring, interval-censoring, truncation
  • Integrates with algebraic.mle: Seamless maximum likelihood estimation with analytical gradients
  • Supports masked data: Handles latent cause-of-failure in competing risks settings

Quick Start

# Install from GitHub
devtools::install_github("queelius/likelihood.model")

# Load the package
library(likelihood.model)

# Create a Weibull likelihood model for right-censored data
model <- likelihood_contr_model(
  obs_type = "right_censored",
  distribution = weibull_distribution()
)

# Fit to data
fit <- mle(model, data = my_data)

Core Concepts

The package is built around the concept of likelihood contributions. Each observation contributes independently to the total log-likelihood:

$$\ell(\theta | \mathbf{x}) = \sum_{i=1}^n \ell_i(\theta | x_i)$$

Different observation types have different contribution forms:

  • Exact: \(\log f(x_i; \theta)\)
  • Right-censored: \(\log S(x_i; \theta)\) where \(S\) is the survival function
  • Interval-censored: \(\log [F(b_i; \theta) - F(a_i; \theta)]\)
