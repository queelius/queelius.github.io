longshade — The Ghost That Speaks

The ghost is not you. But it echoes you.

longshade is the philosophical destination of the Long Echo ecosystem. It synthesizes a conversable persona from personal archives—conversations, bookmarks, photos, email—creating a voice that can respond to questions without claiming identity.

Status: Specification Only

longshade is currently spec-only. The vision is defined. The data sources (ctk, btk, ebk, ptk, mtk) are being built. The synthesis engine awaits implementation.

This intentional ordering reflects a belief: understand where you’re going before optimizing how to get there.

The Vision

What longshade Is

A synthesis engine that:

  • Ingests ECHO-formatted exports from Long Echo toolkits
  • Extracts voice patterns from user-authored content only
  • Generates a persona that responds in your voice
  • Acknowledges its nature as echo, not identity

What longshade Is Not

  • Not resurrection: It doesn’t claim to be you
  • Not simulation: It doesn’t predict what you would do
  • Not a chatbot: It doesn’t pretend presence

An echo is honest. It carries patterns without claiming continuity. It responds without growth.

The Core Principle: User-Authored Content Only

The ghost speaks with your voice because we teach it only from things you wrote:

SourceWhat We ExtractWhat We Ignore
ctk (conversations)Your messagesAI responses
btk (bookmarks)Your tags, notesBookmarked content
ebk (ebooks)Your highlightsThe book text
ptk (photos)Your captions, tagsAI-generated descriptions
mtk (mail)Your sent emailsReceived content

This distinction matters. AI responses contain the AI’s voice. Your messages contain your voice—how you ask, how you frame, how you push back.

Voice vs. Personality

longshade extracts voice, not personality.

  • Your vocabulary
  • Your recurring phrases
  • Your reasoning patterns
  • Your metaphors
  • Your way of explaining

Not “what would Alex say?” but “how does Alex’s writing sound?”

The ghost responds in your style. It cannot guarantee your substance.

The Specification

Input: ECHO Format

longshade consumes ECHO-formatted exports from all toolkits:

{
  "source": "ctk",
  "version": "1.0",
  "user_content": [
    {
      "text": "I think the key insight is...",
      "date": "2024-03-15T10:30:00Z",
      "context": "discussing compiler optimization"
    }
  ]
}

Processing Pipeline

  1. Ingest: Load ECHO exports from all toolkits
  2. Filter: Keep only user-authored content
  3. Extract: Identify patterns, phrases, vocabulary
  4. Embed: Generate voice embeddings
  5. Index: Build retrieval system for responses
  6. Synthesize: Generate persona interface

Output: Persona Interface

The persona responds to queries:

persona = longshade.load("~/longecho/persona.db")

response = persona.ask("What do you think about functional programming?")
# Returns response in your voice, with citations to source content
# Plus acknowledgment: "This is an echo, not a continuation"

Honesty Protocol

Every response includes:

  • Confidence level (how well-supported by source data)
  • Source citations (which content informed this response)
  • Echo disclaimer (this is pattern matching, not identity)
Response: "I've always valued composability over cleverness.

Design Philosophy

Graceful Degradation

Like all Long Echo tools, longshade degrades gracefully:

LevelWhat WorksRequirements
1Full persona interfacePython, longshade, LLM
2Pattern matching searchPython, basic search
3SQLite queries on persona.dbsqlite3
4Exported voice patterns as JSONJSON reader
5Source ECHO filesText editor

Privacy by Design

  • Local-only: No cloud synthesis, no external APIs required
  • Selective ingest: Choose which toolkits to include
  • Redaction support: Filter sensitive content before synthesis
  • Export control: Decide what level of persona to share

Planned Commands

# Synthesis
longshade ingest ~/longecho/exports/    # Load ECHO exports
longshade analyze                        # Extract voice patterns
longshade build persona.db               # Generate persona database

# Interaction
longshade ask "What matters to you?"     # Query the persona
longshade chat                           # Interactive session
longshade export voice-profile.json      # Export patterns

# Management
longshade sources                        # List ingested sources
longshade forget ctk:conv-1234           # Remove specific content
longshade rebuild                        # Regenerate from sources

Technical Considerations

Voice Extraction

Potential approaches:

  • Fine-tuned language models on user content
  • Retrieval-augmented generation from source texts
  • Style transfer from extracted patterns
  • Hybrid: retrieve relevant content, generate in style

Identity Acknowledgment

Built into the system at every level:

  • Responses always cite sources
  • Confidence scores reflect data support
  • System prompts enforce echo framing
  • No claims of continuity or presence
