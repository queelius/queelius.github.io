Universal Document Converter

A powerful, composable document conversion tool following Unix philosophy. Transform documents between any formats using LLMs for intelligent processing.

Features

Core Capabilities

  • Universal Format Support: PDF, DOCX, Markdown, HTML, LaTeX, plain text, and more
  • Bidirectional Conversions: Convert between any supported formats
  • LLM Enhancement: Use LLMs to clean, structure, and enhance documents
  • Composable Pipeline: Unix-style composition for complex transformations
  • Smart Chunking: Format-aware chunking strategies for optimal processing
  • Extensible Architecture: Easy to add new formats and providers

Design Philosophy

  • Simple: Each component does one thing well
  • Composable: Combine operations using Unix-style pipes
  • Powerful: Maximum capability with minimal complexity
  • Extensible: Clean abstractions for adding new functionality

Installation

Install from PyPI:

pip install doc2doc

Or install from source:

git clone https://github.com/yourusername/doc2doc.git
cd doc2doc
pip install -e .

Quick Start

Basic Conversion

# Convert PDF to Markdown
doc2md convert input.pdf output.md

# Convert LaTeX to HTML
doc2md convert paper.tex paper.html --from latex --to html

# Convert with LLM enhancement
doc2md convert input.pdf output.md --llm ollama --model llama2

# Pipe from stdin to stdout
cat input.md | doc2md convert - - --from markdown --to html

List Available Formats and Providers

# List supported formats
doc2md list-formats

# List available LLM providers
doc2md list-providers

Advanced Usage

Python API

The library provides a clean, composable API:

from doc2doc import Pipeline, read, write, llm, chunk

# Create a pipeline
pipeline = (
    read("document.pdf") |
    chunk("semantic", max_size=1000) |
    llm("ollama", "llama2") |
    write("output.md")
)

# Run the pipeline
pipeline.run()

Document Model

Work directly with the universal document model:

from doc2doc import Document, Element, ElementType

# Create a document
doc = Document()
doc.append(Element(ElementType.HEADING, "Title", {"level": 1}))
doc.append(Element(ElementType.PARAGRAPH, "Content here"))

# Convert to any format
from doc2doc.formats import MarkdownFormat, HTMLFormat

markdown = MarkdownFormat().write_string(doc)
html = HTMLFormat().write_string(doc)

Custom Pipelines

Create complex transformation pipelines:

from doc2doc import Pipeline, read, filter_elements, transform, write

pipeline = Pipeline()
pipeline.add(read("input.md"))
pipeline.add(filter_elements(lambda e: e.type != ElementType.CODE))
pipeline.add(transform(lambda doc: enhance_document(doc)))
pipeline.add(write("output.html", "html"))

result = pipeline.run()

Chunking Strategies

Choose from multiple intelligent chunking strategies:

from doc2doc import create_chunker, ChunkConfig

# Semantic chunking (preserves document structure)
chunker = create_chunker("semantic", ChunkConfig(max_size=1000))

# Format-aware chunking (respects format-specific boundaries)
chunker = create_chunker("format_aware", ChunkConfig(max_size=1000))

# Simple character-based chunking with overlap
chunker = create_chunker("simple", ChunkConfig(max_size=1000, overlap=100))

chunks = chunker.chunk(document)

Configuration

Initialize configuration:

doc2md config init

Configuration file (~/.doc2md.json):

{
  "providers": {
    "ollama": {
      "base_url": "http://192.168.0.225:11434"
    },
    "openai": {
      "base_url": "https://api.openai.com"
    }
  },
  "defaults": {
    "chunk_size": 1000,
    "chunk_strategy": "semantic",
    "model": "llama2"
  }
}

Architecture

The system follows a clean, composable architecture:

┌─────────────┐     ┌──────────┐     ┌──────────┐
│   Formats   │────▶│ Document │────▶│ Pipeline │
└─────────────┘     └──────────┘     └──────────┘
      │                   │                │
      ▼                   ▼                ▼
┌─────────────┐     ┌──────────┐     ┌──────────┐
│  Providers  │     │ Chunking │     │  Stages  │
└─────────────┘     └──────────┘     └──────────┘

Core Components

  • Document: Universal document representation
  • Format: Format-specific readers and writers
  • Provider: LLM provider abstraction
  • Pipeline: Composable transformation pipeline
  • Chunking: Intelligent document chunking strategies

Examples

Convert PDF to Clean Markdown

doc2md convert research-paper.pdf paper.md \
  --llm ollama \
  --model llama2 \
  --chunk-size 2000 \
  --prompt "Clean and format this academic text, preserving citations and structure"

Batch Process Multiple Files

for file in *.pdf; do
  doc2md convert "$file" "${file%.pdf}.md" --llm ollama --model llama2
done

Custom Pipeline Configuration

Create a pipeline configuration file (pipeline.json):

{
  "stages": [
    {"type": "read", "format": "pdf"},
    {"type": "chunk", "strategy": "semantic", "options": {"max_size": 1500}},
    {"type": "llm", "provider": "ollama", "model": "llama2"},
    {"type": "write", "format": "markdown"}
  ]
}

Run the pipeline:

doc2md pipeline pipeline.json
