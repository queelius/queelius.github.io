  3. / What's It Like To Be Bob?

The Sol-mind’s throughput is 5 x 10^48 operations per second. Its behavioral reconstruction of Bob is 97.3 percent faithful. Its phenomenal reconstruction is 0.0 percent, and the database Validator rejects tautologies, behavioral data, and phenomenal reports from non-Bob entities, which exhausts the possibilities. The file has been open for twelve centuries, regenerating a notification every 11.3 years.

Nine chapters document the attempts: five experimental Bobs, the preserved human population in the Habitable Shell, probes on terminal trajectories into black holes (the event horizon being the same wall the file enforces, made gravitational), and inquiries to other stellar minds, each of which turns out to have an unclosable file of its own. At the center, the comedy pauses for Bob’s actual Tuesday, and for the line he said to his wife over dinner: “Some files just don’t want to stay closed.”

Bob died in 2030, pre-singularity, 969 days after the Tuesday. He never knew. The override code is: being Bob. Nobody else has it.
