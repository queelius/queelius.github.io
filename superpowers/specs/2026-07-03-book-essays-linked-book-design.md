# Book Essays + `linked_book` Taxonomy: Design

**Date:** 2026-07-03
**Status:** Approved

## Goal

Every published book in `/writing` gets a dedicated behind-the-book blog post, and book pages automatically surface all posts about them, with no two-sided manual list maintenance.

## Current State

- 13 book pages in `content/writing/`, all published on Amazon with buy links rendered by `layouts/writing/single.html`.
- 2 books have dedicated posts: *The Policy* (overview + 5 deep-dives) and *Echoes of the Sublime* (overview + codex + s-risks post). Both maintain `related_posts`/`sidebar_related` bidirectionally by hand.
- 11 books have no dedicated post: Bob, Clankers, Demons at Work, Good As New, Is It Kind?, Measure, Multitudes, On Intelligence, Seven Stories, The Unbegotten, Worldlines.
- `layouts/writing/single.html` renders three related-content blocks: `sidebar_related` (curated sidebar), `related_posts` (manual "Discussion & Related"), and Hugo's automatic `Related` engine.

## Part 1: `linked_book` Taxonomy

Mirrors the existing `linked_project` pattern.

1. **Register taxonomy** in `hugo.toml`: `linked_book = 'linked-books'` (URL `/linked-books/`, no collision with `/writing/`).
2. **Posts declare membership by book slug**: `linked_book: ["bob"]`. Lists allowed; a post may link multiple books (for example, the quantum-series epilogue links `measure`, `multitudes`, and `worldlines`).
3. **Template change** in `layouts/writing/single.html`, "Discussion & Related" section:
   - Auto-collect pages via the taxonomy: all pages whose `linked_book` contains this book's `slug`, sorted by date (newest first).
   - Merge with manual `related_posts` (kept for cross-section curation, such as papers like *On Moral Responsibility*, which are generated by `mf` and must not be edited to carry `linked_book`).
   - Dedupe: a page appearing in both sources renders once. Manual entries keep their current styling precedence.
   - `sidebar_related` unchanged.
4. **Retrofit existing posts** with `linked_book`:
   - `the-policy`: `2024-09-10-the-policy`, `2025-11-04-policy-q-learning`, `2025-11-04-policy-containment`, `2025-11-04-policy-deceptive-alignment`, `2025-11-04-policy-s-risk`, `2025-11-04-policy-cev`
   - `echoes-sublime`: `2024-08-15-echoes-of-the-sublime`, `2025-11-05-echoes-codex`, `2025-11-12-echoes-s-risks`
   - `measure`, `multitudes`, `worldlines`: `12-epilogue-measure-and-meaning`
   - Generated content (`content/papers/`, `content/publications/`) is NOT retrofitted. Those stay in manual `related_posts` on the book pages.

## Part 2: Eleven Behind-the-Book Essays

One post per book lacking one. Format precedent: `2024-09-10-the-policy` (first-person, idea-driven; the book is context, not a sales pitch). Voice reference: `.mf/soul.md`. Seed material: each book page's `description`/`context`/`inspiration` front matter.

**Length:** roughly 1,000 to 2,000 words each.

**Directory naming:** `content/post/YYYY-MM-DD-slug/index.md`, backdated 1 to 3 days after each book's `/writing` date (collisions offset):

| Book | Book date | Post dir |
|------|-----------|----------|
| Is It Kind? | 2026-03-25 | `2026-03-27-is-it-kind` |
| Good As New | 2026-03-26 | `2026-03-28-good-as-new` |
| Seven Stories | 2026-03-25 | `2026-03-29-seven-stories` |
| Clankers | 2026-04-05 | `2026-04-07-clankers` |
| Worldlines | 2026-04-13 | `2026-04-15-worldlines` |
| Demons at Work | 2026-04-13 | `2026-04-16-demons-at-work` |
| Bob | 2026-06-06 | `2026-06-08-what-is-it-like-to-be-bob` |
| On Intelligence | 2026-06-08 | `2026-06-10-on-intelligence` |
| Multitudes | 2026-06-20 | `2026-06-22-multitudes` |
| Measure | 2026-06-24 | `2026-06-26-measure` |
| The Unbegotten | 2026-06-25 | `2026-06-27-the-unbegotten` |

All dates are in the past relative to today, so Hugo's future-date skip does not apply.

**Front matter per post:**
- `title`: essay title (idea-first, not just the book name, matching precedent)
- `date`: from table above
- `linked_book: ["<book-slug>"]`
- `description`: card preview text
- `tags`: drawn from the book page's tags
- `categories`: Fiction/Philosophy/Physics etc. as fits
- `featured_image`: reuse the book cover (`/images/writing/<slug>.jpg`)
- `tts: true`
- `series`: only where a natural fit exists (case by case; for example, Indifference Suite books may join existing series). Not forced.
- `author` block matching precedent posts

**Inline content:** each essay links to its `/writing/<slug>/` page in the body.

## Part 3: Validation & Deploy

- `hugo --gc --minify` must pass (writes to `docs/`; a dirty `docs/` tree is normal).
- `mf health links` if the `mf` CLI is installed (currently not installed; the Hugo build alone is acceptable).
- Commits: one for plumbing + retrofit (taxonomy, template, existing-post edits), then the 11 posts (single commit or per-post; the implementation plan decides).
- Deploy (`make push`) is a separate, user-initiated step.

## Out of Scope

- crier cross-posting campaign for the essays (possible follow-up)
- Audiobook/YouTube link additions
- Changes to the `/writing` list page
- Editing generated content (`content/papers/`, `content/publications/`)
