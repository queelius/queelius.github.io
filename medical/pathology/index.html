Pathology Reports

This section contains pathology reports from tissue biopsies and specimen analysis.

Report Components

Each pathology report includes:

  • Specimen Type — What tissue was examined
  • Clinical History — Indication for biopsy
  • Gross Description — What the tissue looked like to the naked eye
  • Microscopic Description — What was seen under the microscope
  • Immunohistochemistry — Special stains if performed
  • Molecular Studies — Genetic/molecular testing results
  • Diagnosis — Pathological interpretation
  • Comment — Clinical significance if applicable

Diagnostic Studies

Tumor Characterization

  • Tumor type (adenocarcinoma, etc.)
  • Grade (differentiation level)
  • Histological subtype
  • Special features

Genomic Profiling

  • Microsatellite instability (MSI) status
  • KRAS mutation status
  • BRAF mutation status
  • TP53 status
  • Mismatch repair gene status

Prognostic Markers

  • Ki-67 proliferation index
  • Lymphocytic infiltration
  • Vascular invasion
  • Tumor-infiltrating lymphocytes (TILs)

Individual pathology reports are filed with associated specimen information.
