Medical Records - Quick Start Guide

Accessing the Medical Dashboard

Navigate to https://metafunctor.com/medical/ to access the medical records dashboard.

You can also reach it from:

  • Main site navigation menu (top “Medical” link)
  • The blog post: Stage 4: Almost a Year After the Defense

Understanding the Dashboard

The medical dashboard serves as a central index for all health documentation. It includes:

  • Overview — Cancer diagnosis context and treatment approach
  • Navigation shortcuts — Quick links to all subsections
  • Data privacy statement — How medical information is handled
  • Contact information — How to reach out with questions

Using the Sidebar Navigation

On every medical page, you’ll see a sidebar on the right side containing 11 navigation links:

  1. Dashboard — Return to the main overview
  2. Timeline — Chronological view of medical events
  3. Conditions — Active diagnoses (Stage IV colorectal cancer, etc.)
  4. Medications — Current treatment protocol and supporting drugs
  5. Encounters — Medical appointments and hospital visits
  6. Labs — Laboratory test results with trends
  7. Imaging — CT scans, MRI, and other radiological studies
  8. Pathology — Biopsy reports and tissue analysis
  9. Surgical — Surgical procedures and operative reports
  10. Notes — Clinical documentation and provider notes
  11. Analysis — Synthesized clinical analysis and research
  12. Sources — Documentation of data sources and methodology

Navigation Tips:

  • The current page link is highlighted in blue
  • Click any link to navigate to that section
  • The sidebar stays visible as you scroll
  • On mobile devices, the sidebar appears below the main content

Understanding the Information

Front Matter

Each medical record includes metadata at the top (not visible on the page):

  • Title — What the page is about
  • Date — When the medical event occurred
  • Categories — All pages are “medical” and “personal”
  • Tags — Specific keywords (e.g., “cancer”, “stage-4”, “labs”)

Content Format

Medical records use standardized formatting:

Tables — Lab results and encounter data are shown in tables with columns for:

  • Test name or Encounter type
  • Date — When the test/appointment occurred
  • Value — Result, reference range, or assessment
  • Status — Normal, abnormal, or clinical significance

Sections — Documents are divided into clear sections:

  • Overview or summary
  • Detailed findings or results
  • Clinical impression or assessment
  • Next steps or follow-up

Breadcrumbs — At the top of each page showing your location:

Home / Medical / [Current Section]

Searching for Information

Using Site Search

  1. Go to Search
  2. Type a keyword or phrase:
    • Medical terms: “CEA”, “creatinine”, “imaging”
    • Dates: “February 2025”, “January”
    • Topics: “chemotherapy”, “appointments”, “CT scan”
    • Medication names: “FOLFIRI”, “Bevacizumab”

Medical pages appear in search results with:

  • Title — The page name
  • Section — Will show “medical”
  • Content preview — First 500 characters

Filtering Search Results

After searching, you can filter by:

  • Section — Select “medical”
  • Tags — Select specific tags like “cancer” or “treatment”
  • Categories — Select “medical”

Understanding Medical Abbreviations

Common abbreviations used in medical records:

Diagnoses & Types

  • IV — Intravenous
  • CT — Computed Tomography
  • MRI — Magnetic Resonance Imaging
  • CEA — Carcinoembryonic antigen (tumor marker)

Lab Tests

  • CBC — Complete Blood Count
  • CMP — Comprehensive Metabolic Panel
  • LFTs — Liver Function Tests
  • AST/ALT — Liver enzymes

Medications

  • 5-FU — 5-Fluorouracil (chemotherapy)
  • FOLFIRI — Fluorouracil + Leucovorin + Irinotecan protocol
  • IV — Intravenous administration

See Sources for more detailed definitions and medical context.

Interpreting Results

Lab Values

Lab results show:

  1. Test name — What was measured
  2. Result — The actual value
  3. Reference range — Normal range for that test
  4. Status — Whether the value is normal or abnormal

Example:

| Test | Value | Reference | Status |
|------|-------|-----------|--------|
| Hemoglobin | 11.2 | 12.0-16.0 | Low |

The hemoglobin value (11.2) is below the normal range (12.0-16.0), so it’s marked as “Low”.

Imaging Reports

Imaging reports include:

  1. Study type — What was imaged (e.g., “CT Abdomen/Pelvis”)
  2. Date — When the study was performed
  3. Findings — Description of what was seen
  4. Impression — Clinical interpretation

Clinical Notes

Clinical notes follow a standard format:

  1. Date & provider — When and by whom
  2. Assessment — Clinical impression and problem list
  3. Plan — Treatment recommendations and next steps
  4. Follow-up — When to return, what to watch for

Privacy & De-identification

All medical records in this section:

  • Are publicly shared for educational and research purposes
  • Have removed identifiers (no patient ID numbers, specific provider names)
  • Use generalized facility names (not specific hospital identifiers)
  • Do not include genetic data or sensitive social information

See Sources for complete privacy information.

Navigating on Mobile

On mobile devices:

  1. Sidebar appears below content — Scroll down to see navigation
  2. Breadcrumb at top — Shows where you are
  3. Tap navigation links — Sidebar links are touch-friendly
  4. Tables may scroll — Wide tables scroll horizontally on small screens
  5. One-column layout — All content stacks vertically

Mobile navigation tip: Use the breadcrumb at the top to go back to “Medical” then select a new section.

Getting Help

Common Questions

Q: Is all this information accurate? A: This information is transcribed from official medical records. While care is taken to maintain accuracy, it represents patient records and may contain transcription or formatting variations.

Q: Can I use this for medical advice? A: No. This is a personal medical record repository. Always consult healthcare providers for medical decisions.

Q: Can I share this information? A: Yes, this is publicly shared information. Attribution to metafunctor.com is appreciated.

Q: Are there gaps in the data? A: Yes. Some early records may be unavailable, and documentation may be incomplete for certain periods.
